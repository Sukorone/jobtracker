# Job Tracker

Трекер откликов на вакансии: канбан-доска, фокус на сегодня и аналитика воронки.

**Открыть:** https://sukorone.github.io/jobtracker/

## Возможности

- **Доска** — отклики по этапам: Хочу → Отклик → Скрининг → Интервью → Тестовое → Финал → Оффер / Отказ. Карточки перетаскиваются мышью, на телефоне долгим нажатием.
- **Фокус** — просроченные шаги, дела на сегодня и на неделю, а также отклики «в тишине», о которых пора напомнить. Шаг можно закрыть одной кнопкой или добавить в календарь (.ics).
- **Карточка отклика** — все поля, следующий шаг с датой и временем, заметки, автоматическая история смены статусов, шаблоны писем (напоминание, спасибо после интервью, уточнить сроки).
- **Аналитика** — отклики по неделям, воронка с конверсией между этапами, ответы по источникам (hh.ru, LinkedIn, Хабр…), распределение по статусам.
- **Список** с сортировкой, поиск, фильтры по приоритету, источнику и формату, архив.
- Тёмная и светлая темы, PWA (можно установить на телефон, работает офлайн).
- Экспорт в JSON (бэкап) и CSV (Google Sheets / Excel), импорт JSON.

Данные хранятся в [Supabase](https://supabase.com) (бесплатный тариф) под логином и паролем: заходите с телефона или компьютера, свой сервер не нужен. Регистрация закрыта. Тема и вид — настройки устройства, они остаются в браузере.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `N` | новый отклик |
| `/` | поиск |
| `1` `2` `3` | доска / список / аналитика |
| `Ctrl/⌘ + Enter` | сохранить новый отклик |
| `Esc` | закрыть панель |

## Бэкенд (Supabase)

- Схема и права доступа — [`supabase/schema.sql`](supabase/schema.sql): одна таблица `applications`, Row Level Security — каждый видит только свои записи.
- Адрес проекта и publishable-ключ лежат в `.env`; они публичные, доступ к данным защищают RLS-политики.
- Логин `alex` превращается в email `alex@jobtracker.local` — так Supabase хранит учётку.
- Workflow [`keepalive.yml`](.github/workflows/keepalive.yml) раз в 3 дня пингует базу, чтобы бесплатный проект не засыпал.

Новая учётная запись: Supabase → **Authentication → Users → Add user → Create new user**, email `<логин>@jobtracker.local`, пароль, галочка **Auto Confirm User**.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173/jobtracker/
npm run build
```

Стек: Vite, React 19, TypeScript, Zustand, dnd-kit, Motion, Supabase. Деплой на GitHub Pages через GitHub Actions при пуше в `main`.
